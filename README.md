# Shubhang Rathore — Website

Personal website of **Shubhang Rathore**, Solution Architect.

**Live site:** <https://shubhangrathore.com>

## About

A single-page personal site: name, tagline, contact email, and links to GitHub and Google Play.

Built with plain HTML and CSS — no frameworks, no JavaScript, no build step.

## Run locally

Serve this folder with any static file server:

```sh
python3 -m http.server
```

Then open <http://localhost:8000/>.

No installation required.
